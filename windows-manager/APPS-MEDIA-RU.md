# Исправление Wi-Fi, управление приложениями и W:\.intake

Эта версия расширяет существующий Windows-менеджер. Новый Android-лаунчер не
требуется. Никаких изменений на домашнем оборудовании из облака не выполнялось.

## Ошибка на 192.168.31.232:5555

Текст «Wi-Fi сохранена приложением первоначальной настройки» означает, что
Free My TV установлен, но остановил **переключение Home**. Android удаляет сети,
сохранённые приложением, когда оно отключается. Free My TV защищает вас от этого.
Переустановка Free My TV не исправляет владельца сети. Защита не ослаблена.

1. В менеджере нажмите «Почему не включается Free My TV?». Для каждого ТВ
   сохраняется launcher-diagnosis.json: текущий Home, пакеты владельцев Wi-Fi,
   наличие профильного интерфейса. SSID и пароли в этот отчёт не входят.
2. Предпочтительно подключите проблемную приставку по Ethernet. Забывание
   активной Wi-Fi-сети может оборвать ADB: менеджер сети не забывает.
3. На ТВ: Настройки → Сеть и Интернет → сохранённая сеть → Забыть. Подключитесь
   заново именно из обычных сетевых настроек. Пароль нужен вам, не менеджеру.
4. Повторите диагностику. Если первоначальная настройка всё ещё в блокировщиках,
   есть другие её сохранённые сети, возможно вне зоны. Не отключайте setupwraith,
   не меняйте сохранённые настройки HomeMode и не выполняйте сброс. Для таких
   записей нужен отдельный просмотр сетевых ID на вашем Windows и выбор конкретных
   сетей перед удалением — данный выпуск не удаляет их автоматически.
5. Переключение Home выполняйте на самом ТВ после устранения причины. На
   Android 9/10 перед переключением отключите ADB компьютера. Original/watchdog
   сохранены; сам менеджер Home не переключает.

## Только профиль, без повторной установки приложений

Нажмите «Применить русский язык и кнопку сети». На приставках с профильным
Free My TV меняются только language и topButtons. Избранное и прочие параметры
не перезаписываются. Проверяется фактический экспорт после применения.
Проектор-источник исключён. Отмена — существующая кнопка восстановления UI-профиля.

Если установленная версия не имеет ProfileInbox, произвольная запись её private
preferences невозможна. Обновление только Free My TV возможно отдельно с проверкой
подписи: в разделе установки выберите только Free My TV. При несовпадении подписи
обновление пропускается. Проектор не обновляется. Не удаляйте работающий лаунчер
ради несовпадения сертификата.

## Просмотр, отключение и удаление приложений

1. Выберите устройство в разделе управления приложениями. Нажмите «Прочитать
   список приложений». Фильтры показывают сторонние, системные/защищённые,
   отключённые и удалённые записи, сохранённые Android. Это не полная история всех
   когда-либо удалённых приложений. Если Android забыл запись, её здесь не будет.
2. Смотрите package name. Название известно для приложений из каталога; остальные
   показываются по package name. «Настройки на ТВ» открывают штатную карточку,
   где можно посмотреть название и фактические объёмы данных/кэша.
3. Отметьте только знакомые ненужные сторонние приложения. По умолчанию ничего
   не выбрано. Системные и критические компоненты менеджером не изменяются.
   Совпадение advert/demo/analytics в имени не доказывает ненужность.
4. Выберите действие, нажмите «Показать точный план и подтвердить». План привязан
   к адресу, идентификатору устройства, исходным состояниям и имеет срок 3 минуты.
   При изменении состояния требуется новый план. Перед первым изменением снова
   проверяются все выбранные пакеты.
5. Для отключения используется disable-user --user 0. APK и данные остаются.
   Для удаления — uninstall -k --user 0, только сторонние приложения: сначала
   сохраняются и проверяются base APK и все splits. -k запрашивает сохранение
   данных, но это не полная резервная копия аккаунтов/серверных данных.
6. В отчёте перечисляется результат каждого пакета, свободное хранилище /data,
   доступная ОЗУ и число процессов до/после. Кэш и пользовательские данные
   менеджер не очищает. Отключение не освобождает место APK. Удаление может
   освободить место кода; объём сохранённых данных остаётся. Изменение ОЗУ
   при текущей нагрузке не доказывает ускорения.
7. «Отменить последнюю операцию приложений» возвращает точное enabled-state
   (включая default-state), либо устанавливает сохранённые APK той же версии и
   подписи. Android может отказать; downgrade, root и очистка данных не используются.
   Позднейшие изменения не перезаписываются. Повторная отмена переходит к предыдущей
   операции. Журналы остаются в data/reports, не загружаются на GitHub.

Удаление системных APK, выключение Cast/AirPlay/Miracast, сети, Bluetooth,
HDMI, DRM, Play Services, системных настроек, служб изображения и безопасности
не реализовано. Удаление сторонних приложений не гарантирует ускорения.

## Настроить Windows и передать папку на каждый ТВ

Для вашего локального W:\.intake:

1. Укажите эту папку и проверьте актуальные три IP. Выберите плеер.
2. Нажмите «НАСТРОИТЬ УЖЕ УСТАНОВЛЕННОЕ: Windows + профиль + папка».
   Если ресурса ещё нет, откроются UAC и окно создания отдельной read-only
   учётной записи. Задайте пароль и сохраните у себя. Пароль в менеджер не передаётся.
   Программа дождётся результата именно этого окна; старый success не считается.
3. Создаются SMB2/3-ресурс, отдельный пользователь, разрешение только чтения и
   Private-правило TCP 445 только для IP ваших ТВ. Не включаются SMB1, гости,
   публичные правила, проброс порта или автоматическая смена профиля сети Windows.
4. На приставках применяется минимальный UI-профиль, затем для каждого устройства
   проверяется TCP 445 и выбранному плееру передаётся SMB-адрес через публичный
   ACTION_VIEW, если установленная версия объявляет подходящий обработчик.
   Отсутствие TCP-инструмента в прошивке отображается как «неизвестно».
5. На ТВ проверьте, что плеер открыл папку. Если запрошены пользователь и пароль,
   введите их в самом плеере. Сохраните источник/избранное штатной кнопкой плеера.
   Для другого плеера выберите его и нажмите «Проверить доступ с ТВ и передать адрес».

**Границы автоматизации.** ACTION_VIEW не является универсальным API добавления
постоянного SMB-источника. VLC принимает SMB Intent, но это не доказывает импорт
папки и сохранение учётных данных. Для Vimu/MX поддержка проверяется на установленной
версии: при отсутствии обработчика выводятся ручные параметры. Менеджер не пишет в
закрытые базы этих приложений, не использует root и не имитирует ввод пароля/согласия.
Полностью автоматическое сохранение папки с авторизацией во всех трёх плеерах
в этом комплекте **не заявляется**. TCP-доступность, запуск Activity, авторизация
и чтение фильма — разные результаты. Последние два требуют проверки на реальном ТВ.

В выбранном ресурсе уже содержится сама .intake: не добавляйте /.intake повторно.
Подробные поля VLC/Vimu/MX: W-INTAKE-RU.md. Если у MX нет нужной поддержки SMB,
используйте X-plore из официального магазина и открытие файла через MX.
Между проектором 192.168.28.60 и приставками 192.168.31.x нужна существующая
домашняя маршрутизация. Этот менеджер не перенастраивает роутер.

Отчёт media-handoff.json сохраняет поля ресурса без пароля, TCP-результаты
Windows/ТВ и результат Intent. Поля source_saved и authenticated_read_verified
остаются false: запуск приложения не выдаётся за проверенное чтение медиатеки.

# Xiaomi TV Manager 2 — единый центр управления тремя Android TV

Одна программа на Windows 10/11 x64 для проектора Mi Smart Projector 2 Pro и двух
Mi Box S: проверка, установка своих APK, приложения и очистка, профиль Free My TV,
медиатека `W:\.intake`, INCY/YouTube, пульт и журнал. Всё — через интерфейс в
браузере, без IDE, без установки Python и без ввода команд.

## Первый запуск (5 минут)

1. Скачайте `XiaomiTVManager-Windows.zip` (ссылка — в описании Pull Request) и
   проверьте SHA-256 из файла `XiaomiTVManager-Windows.zip.sha256`, если умеете.
2. Свойства ZIP → «Разблокировать» (если есть) → «Извлечь всё» в **короткий** путь,
   например `C:\XiaomiTVManager` или Рабочий стол. Java в Windows не запускается из
   путей длиннее 260 символов — менеджер скажет об этом понятной ошибкой.
3. Дважды нажмите `START.bat`. Откроется браузер с менеджером. Окно консоли не
   закрывайте: закрытие консоли завершает менеджер.
4. Вверху — три карточки устройств. IP уже заполнены (`192.168.28.60`,
   `192.168.31.232`, `192.168.31.20`). Нажмите «Подключить» у каждой. Если на ТВ
   появится «Разрешить отладку?» — подтвердите на ТВ и отметьте «Всегда».
5. Раздел «Устройства» → **Проверить выбранные ТВ**. Это только чтение. В карточках
   появятся модель, Android/API, архитектура, свободное место `/data`, доступная ОЗУ,
   текущий главный экран, сеть и состояние VPN.
6. При первой проверке APK менеджер сам скачает официальные Temurin JRE 17 и Android
   Build Tools 34 в свою папку `runtime` и сверит их закреплённые суммы.

ADB ожидается в `C:\platform-tools\adb.exe`. Галочка у карточки — цель следующего
действия. Проектор — источник настроек: его лаунчер, проекционные настройки и AirCast
менеджер не меняет (защита работает и по IP, и по серийному номеру).

## Свои APK

1. «Свои APK» → перетащите `.apk`, `.apks` или `.xapk` в рамку, нажмите «Выбрать файл…»
   или вставьте HTTPS-ссылку. Файл идёт потоком на диск (до 1 ГБ) с прогрессом и
   кнопкой отмены; недокачанные части удаляются.
2. Менеджер показывает: название и иконку, package, versionName/versionCode,
   минимальный и целевой API, архитектуры, SHA-256 файла и сертификата, схемы подписи,
   формат (полный APK / комплект) и происхождение: «совпадает с каталогом», «тот же
   издатель, что в каталоге», «неизвестный издатель» или «подпись НЕ совпадает с
   каталогом» (установка запрещена).
3. Отметьте ТВ галочками → «Проверить на выбранных ТВ». Для каждого ТВ отдельно:
   совместимость API/ABI, место, установлена ли программа, совпадает ли подпись,
   не будет ли понижения версии. Перед обновлением установленная версия (base и все
   split) копируется и проверяется.
4. «Установить по плану» (план действует 3 минуты и перепроверяется). Результат по
   каждому ТВ: «Установлено и проверено», «Обновлено и проверено», «Уже установлено»,
   «Нельзя установить» с причиной или «Нужно действие на ТВ» (Play Protect).

Не делается никогда: удаление старой версии при конфликте подписей, очистка данных,
понижение версии, флаги `-d`/`-t`/`-g`, отключение Play Protect или проверки TLS.
Комплекты с OBB-данными и зашифрованные APKM не устанавливаются (объяснение показывается).

## Что работает, а что требует действия на ТВ

Проверено на ваших реальных устройствах 27.10.2026 (только чтение, ничего не менялось):
подключение и состояние ADB всех трёх ТВ; проверка; анализ 136 пакетов приставки №1 с
размерами; загрузка Vimu Installer по ссылке, совпадение с каталогом, план для обеих
приставок («уже установлено», подпись сверена с установленным APK); разбор сохранённых
сетей Wi-Fi; диагностика Home; снимок экрана; список приложений для запуска.

Требует действия на ТВ: первое разрешение отладки; запросы Play Protect при установке;
ввод логина/пароля SMB в плеере и сохранение папки в плеере; согласие Android на VPN;
перенос подписки INCY (Send to TV/QR) и импорт профиля ByeByeDPI; включение режима
Free My TV (Free My TV → Главный экран).

Не поддерживается и почему: автоматическое сохранение SMB-источника с паролем внутри
VLC/Vimu/MX (нет публичного API, а запись в их закрытые настройки требует root);
изображение экрана в реальном времени (scrcpy не встроен, см. RESEARCH-RU.md);
доступ извне домашней сети (отдельная задача; порты не пробрасываются).

# Xiaomi TV Manager — Windows 10/11 x64

Это переносимый комплект с графическим интерфейсом в вашем браузере, Python
включён в готовый ZIP. Устанавливать Python, IDE или вводить команды не нужно.
Сервер интерфейса слушает только 127.0.0.1 на случайном порту и требует
случайный токен; никакие файлы компьютера не публикуются в локальную сеть.
Окно работает, пока открыта консоль START.bat. Это не фоновая служба Windows.

## Первый запуск

1. Скачайте `artifacts/XiaomiTVManager-Windows.zip` из ветки
   `feature/incy-profiles-media` вашего fork `namedotm/free-my-tv`.
2. В свойствах скачанного ZIP, если есть пункт «Разблокировать», отметьте его.
   Затем «Извлечь всё» в обычную доступную для записи папку, например «Документы».
   Не запускайте START.bat внутри ZIP. Не отключайте защиту Windows и не
   обходите политику вашей организации. Комплект не имеет подписи Windows EXE.
3. Откройте папку XiaomiTVManager и дважды нажмите START.bat. Откроется браузер.
   Готовый ZIP содержит официальный переносимый Python из NuGet PSF, с его
   лицензиями. При запуске из исходников bootstrap скачает тот же пакет и
   сверит закреплённую SHA-256. Windows ARM/32-bit в этот комплект не входят.
4. ADB ожидается по адресу `C:\platform-tools\adb.exe`. Укажите IP приставок.
   IP проектора уже заполнен: `192.168.28.60`. Можно добавить `:порт`.
5. На каждом ТВ должна быть разрешена отладка. Включение отладки и согласие
   «Разрешить USB-отладку этому компьютеру» выполняются вами на экране ТВ.
   Менеджер не включает ADB, не меняет порт и не обходит авторизацию.
   Если Android требует предварительного `adb pair`, сначала выполните штатное
   сопряжение средствами Android/ADB; формы ввода кода pairing в этой версии нет.
6. Нажмите **Проверить подключения**. Это только чтение: модель, Android/API,
   ABI, свободное место /data, пакеты и версии, память, CPU, процессы и доступная
   статистика кадров. APK не устанавливаются; приложения не запускаются.
7. Выберите приложения и нажмите **УСТАНОВИТЬ НА ВСЕ УСТРОЙСТВА**. При первом
   шаге установки менеджер скачает официальный Temurin JRE и Android Build
   Tools 34 в свою папку runtime, сверит закреплённые контрольные суммы и
   использует Java/apksigner/aapt2 для проверки APK. Нужен интернет. Это не
   установка системной Java. Google SDK используется на условиях его лицензии.
   Ошибка одной приставки не прерывает остальные.

Если браузер не открылся, проверьте браузер по умолчанию в Windows и перезапустите
START.bat. Журналы хранятся рядом с программой, а не отправляются разработчикам.
Не запускайте два экземпляра из одной и той же папки одновременно.

## Что выполняется автоматически

- Каждый адрес проверяется как домашний IPv4. Модели, API и ABI определяются
  отдельно: одинаковое имя Mi Box не считается одинаковой прошивкой.
- APK выбирается по ABI, проверяются minimum API, официальный опубликованный
  SHA-256, криптографическая подпись и закреплённый сертификат. Без нужной
  проверки шаг пропускается, защитные механизмы не отключаются.
- Каталог на 27.10.2026: SmartTube stable 32.68, ByeByeDPI 1.8.2, VLC 3.7.1,
  Free My TV с кнопкой сети и переносом UI-профиля (versionCode 4), INCY Android 3.8.1.
  Исходный APK versionCode 3 сохранён отдельно. Источники и суммы в catalog.json.
  Перед SmartTube/ByeByeDPI проверяется официальный latest-релиз: если он
  изменился/исчез или digest больше не совпадает, установка останавливается
  для этого приложения до обновления каталога. Не используется произвольный
  «самый свежий» APK с новым неизвестным ключом.
- Установленные base APK и splits копируются в отчёт и проверяются до обновления.
  При разных сертификатах или уже более новой версии обновления не будет.
  Если не удалось сохранить или проверить установленную версию, шаг пропускается.
- Используется только `adb install -r`: без удаления, очистки данных, downgrade,
  выдачи всех разрешений, смены Home, выключения Play Protect или root.
  После Success повторно проверяется реально установленный APK, версия и подпись.
- При повторном запуске сверяется фактическое состояние пакетов; такая же или
  более новая версия повторно не устанавливается. Кнопка повтора берёт только
  ошибочные шаги предыдущей установки. Сменившееся устройство по тому же IP
  не наследует выполненные шаги; успешные шаги на неизменившемся устройстве сохраняются.
- Отдельный JSON-профиль ByeByeDPI создаётся только с реально установленными
  SmartTube и, по выбору, официальным YouTube. Пустой белый список запрещён.
  Файл копируется в Download под уникальным именем, старые файлы не заменяются.

На проекторе с официальной Free My TV ожидается конфликт подписи персонального
APK. Это штатный безопасный пропуск, а не причина удалять работающий лаунчер.
Ручной переход требует отдельного плана резервирования и возврата Original.
Даже на новой приставке менеджер только устанавливает приложение: Home не активирует.

## Что нужно подтвердить на телевизоре

**SmartTube.** Разработчик сообщил о заражённой среде сборки и возможной
компрометации ключей. В официальном README описаны восстановление среды и
проверки VirusTotal. Проверенные SHA-256 и подпись подтверждают, какой файл
скачан с официального источника, но не доказывают отсутствие вредоносного кода.
Не выключайте встроенную защиту. Вход по коду и воспроизведение проверяются вами.
Ни мосты SmartTube, ни замена официального YouTube не устанавливаются.

**ByeByeDPI.** VPN не запускается менеджером ни при установке, ни при подготовке
профиля. Важно: первый запуск приложения без импорта может использовать
исходную глобальную конфигурацию. НЕ нажимайте подключение до следующих шагов:

1. В ByeByeDPI экспортируйте прежние настройки, если приложение уже использовалось.
2. Откройте Настройки → меню → Импорт настроек и выберите файл
   `Download/XiaomiTV-YouTube-only-….json`. Отметьте разделы «Настройки» и
   «Приложения». Исходные настройки этой программы будут заменены импортом.
3. Проверьте режим VPN, режим списка **белый список** и состав: только
   `org.smarttube.stable`/`org.smarttube.beta`, при необходимости
   `com.google.android.youtube.tv`. Фактический файл содержит только установленные
   из этого списка приложения. VLC, Vimu, MX Player, AirCast и системных пакетов
   там быть не должно. Автозапуск и автоподключение выключены.
4. Только после проверки включите соединение и подтвердите системный запрос VPN.
   Не включайте Android «Блокировать подключения без VPN» и Always-on VPN.
5. Откройте SmartTube и запустите видео. Затем отдельно откройте фильм из SMB в
   VLC/Vimu, проверьте AirCast/Chromecast. Повторите для Ethernet и Wi-Fi в одной
   домашней сети, без изоляции клиентов. Успех ADB не доказывает маршрутизацию
   приложений или доступность YouTube. Если проверка не прошла — остановите VPN.
6. Не удаляйте все приложения белого списка, пока VPN включён: Android при
   отсутствии действующих разрешённых пакетов может обработать фильтр иначе.
   Перед удалением SmartTube остановите ByeByeDPI.

Параметры обхода зависят от провайдера. Профиль задаёт границы приложений,
но не гарантирует обход ограничений. Работа и импорт на реальном Android TV
ещё требуют проверки; установщик не заявляет автоматическую проверку видео.

**Vimu.** Менеджер автоматически скачивает `VimuInstaller.apk` с официального
`get.vimu.tv`, проверяет закреплённые SHA-256 и сертификат и устанавливает
`net.gtvbox.installer`. Затем на ТВ откройте Vimu Installer и подтвердите
установку самого плеера. Руководство разработчика отдельно описывает лицензию
платной версии; менеджер не выполняет оплату или активацию. Если плеер
`net.gtvbox.videoplayer` уже установлен, он не меняется и Installer не нужен.
Установка Installer отмечается как «Действие на ТВ», а не как готовый плеер.

**MX Player.** Пока используется официальный магазин на ТВ: подтверждённый прямой
APK из текущего официального источника не найден. Открытие магазина не считается
установкой. APK-каталоги и непроверенные файлы не используются.
AirCast на проекторе не затрагивается; новых AirPlay-приёмников менеджер не ставит.

## Медиатека Windows: SMB2/3, только чтение

1. Выберите обычную локальную папку с фильмами на NTFS. Не используйте корень
   диска, системную папку, сетевой путь, symlink или junction.
2. В параметрах Windows убедитесь, что ваша домашняя сеть имеет профиль
   «Частная». Если SMB1 уже включён, отключите его в компонентах Windows.
   Менеджер сам глобальные параметры SMB и профиль сети не меняет.
3. Нажмите **Настроить общую папку** или отметьте создание SMB после установки.
   Подтвердите UAC. Откроется отдельное окно Windows: придумайте пароль минимум
   14 символов и повторите его. Сохраните его самостоятельно. При политике
   сложности Windows соблюдайте также её требования.
4. Создаются только новые ресурсы с уникальными именами: `TVMRead_<id>` (пользователь),
   `TVMovies_<id>` (общая папка), `XiaomiTVManager_<id>` (правило TCP 445).
   Общий ресурс даёт единственной новой учётной записи только Read; NTFS получает
   только ReadAndExecute. Права на запись по SMB не предоставляются.
5. Новое правило брандмауэра разрешает TCP 445 с указанных IPv4 только на Private,
   с запретом edge traversal. Прежние правила не изменяются и могут разрешать
   более широкий доступ к уже существовавшему SMB. Никогда не перенаправляйте
   порт 445 на роутере и не публикуйте SMB в интернет. Не используйте гостя/SMB1.
6. Результат показан в отдельном окне: имя ПК/IP, ресурс, пользователь. Пароля
   там нет. В `data/smb-result.json` сохранена та же информация без пароля.
7. В VLC: «Локальная сеть» → SMB → IP компьютера → ресурс. Введите указанное
   имя пользователя `ИМЯ-ПК\TVMRead_<id>` и ваш пароль. Если поиск не находит ПК,
   добавьте сервер по IPv4 вручную; SMB2/3 должен быть доступен через TCP 445.
8. В Vimu: добавление сетевого источника SMB → IP, ресурс, пользователь и пароль.
   Автоматический импорт учётных данных плееров не используется: документированного
   общего интерфейса нет. Пароль вводится непосредственно в плеере.
9. MX Player: поддержка сети зависит от версии. Если нет SMB2/3-источника,
   используйте легально установленный X-plore из Google Play: LAN → добавить
   SMB-сервер → открыть файл через MX Player. X-plore автоматически не ставится.
10. Убедитесь, что файл воспроизводится, а создать/удалить файл по этой учётной
    записи невозможно. Фактическую проверку чтения с ТВ выполняете вы.

Повторное нажатие не создаёт новые учётные записи: менеджер сообщает о своём
существующем ресурсе. Для другой папки, IP или забытого пароля сначала выполните
восстановление SMB, затем создайте ресурс заново. Политика срока действия пароля
Windows сохраняется; менеджер не отключает её.

## Восстановление и отчёты

- **Восстановить настройки SMB** запросит UAC и отдельное подтверждение. Проверит
  журнал владения, путь ресурса, группу правила, SID пользователя и удалит только
  созданные им объекты и точное собственное разрешение чтения. Фильмы не удаляются.
  Изменившиеся чужие объекты не удаляются автоматически. Полный исходный SDDL
  сохранён для диагностики, но не применяется поверх позднейших изменений ACL.
- Приложения автоматически не удаляются. APK до обновления, включая splits,
  находятся в `data/reports/<IP>/<сеанс>/backups`. Это не резервная копия данных
  приложения. Android может запретить понижение версии; менеджер не обходит
  этот запрет удалением или очисткой данных.
- Для ByeByeDPI: остановить VPN на ТВ, импортировать свой прежний экспорт.
  Если раньше приложения не было, достаточно оставить VPN остановленным;
  удаление нового приложения при желании выполняется вами через настройки ТВ.
- Free My TV: Original/watchdog не менялись. Работающий официальный лаунчер
  при конфликте сертификатов остаётся установленным, выбранный Home сохраняется.
- В `data/logs/<IP>.jsonl` — отдельный журнал каждого устройства;
  `before.json` — исходные свойства/пакеты/версии/память;
  `after.json` — повторные CPU/память/процессы/кадры;
  `install.json` — результат шагов;
  `launch-vlc.json` — измерение запуска по отдельной кнопке.
- Диагностические отчёты могут содержать IP, серийный номер и имена приложений.
  Они исключены из Git и готового ZIP. Не публикуйте отчёты целиком.
- Никакого debloat нет. Эвристический список telemetry/analytics/demo в отчёте
  — только кандидаты для исследования, не список безопасных отключений.
  Cast, AirCast, Miracast, настройки, сеть, Bluetooth, HDMI, DRM, Google Services,
  изображение, звук, автофокус и коррекция трапеции не отключаются.
- До/после не доказывает ускорение: загрузка и кэши могут отличаться. Отдельный
  замер запуска VLC использует am start -W без force-stop/очистки данных; он может
  быть тёплым. Для сравнения повторяйте одинаковые действия с одинаковым контентом.

## Проверки разработки и известные ограничения

`python -m unittest discover -s tests -v` запускает тесты без подключения к ТВ.
`TVM_REAL_TOOLS=1` дополнительно проверяет настоящий уже подписанный APK через
apksigner; на Windows при необходимости скачивает инструменты проверки.
Windows CI проверяет также синтаксис сценариев и сборку ZIP. Ни CI, ни тестовые
ответы ADB не доказывают работу на ваших телевизорах или реальную SMB-сессию.
Результат запуска CI смотрите в GitHub Actions, не путайте его с полевым тестом.

Графический интерфейс, UAC, создание учётной записи/SMB и импорт ByeByeDPI требуют
первого теста на вашем Windows/ТВ. На реальном оборудовании из облака ничего не
запускалось. Начните с «Проверить подключения», затем с одной запасной приставки.


## Исправления по первому полевому отчёту

- Для установленного из магазина VLC поддерживаются config split APK без
  собственного uses-sdk. Минимальный API проверяется по базовому APK, подписи и
  версии всех частей продолжают проверяться. Отдельный split не принимается
  вместо полного скачанного APK. Новый официальный VLC armeabi-v7a проверен
  на метаданные и подпись с API 30 и 34 в тестах, без установки на реальные ТВ.
- У каждого приложения показаны этапы источника, скачивания, подготовки
  инструментов, проверки APK, резервной копии, установки и проверки на ТВ.
  Скачивание показывает реальные МБ и процент от Content-Length; если размер
  неизвестен, показываются полученные МБ и неопределённая полоса.
- Установка APK показывает этап и прошедшее время. ADB не предоставляет честный
  процент установки — он не выдумывается. Общий счётчик означает обработанные
  приложения, а успешные, ошибочные, пропущенные и ручные шаги показаны отдельно.
- «Завершено с ошибками» больше не заменяется сообщением об общем успехе.
  Технические сведения раскрываются прямо в карточке и сохраняются в журнале:
  код Android/инструмента, этап и очищенный вывод без URL-токенов.
- По первому скриншоту невозможно доказать причину сбоя Free My TV на Android 14.
  Новый менеджер покажет конкретный INSTALL_FAILED_* или ошибку проверки APK.
  Защита подписи, запрет downgrade/удаления и исходный APK не менялись.

### Обновление комплекта на Windows

Закройте старую консоль START.bat. Распакуйте новый ZIP и замените файлы программы
в прежней папке XiaomiTVManager. Не удаляйте её `data` и `runtime`: сохранятся
введённые IP, отчёты, кэш и выполненные шаги. Снова откройте START.bat и нажмите
«Повторить неудачные шаги». Если работа с Vimu раньше остановилась на магазине,
выберите Vimu и запустите обычную установку: прежний ручной шаг не считается
ошибочным и сам не попадёт в повтор. Установленные актуальные APK не переустанавливаются.

# Доступ проектора и приставок к W:\.intake

Нужна одна папка, доступная по SMB2/3 только на чтение. На ТВ не вводится
`W:\.intake`: это путь Windows. На ТВ используются сервер, общий ресурс,
подпапка (если нужна), пользователь и пароль.

## Самый короткий путь

1. На Windows откройте `W:\.intake` в Проводнике и убедитесь, что фильмы на месте.
2. Запустите START.bat. В поле медиатеки уже указано `W:\.intake`.
3. Нажмите **«Как подключить папку в плеерах»**. Менеджер проверит, локальный
   ли диск W: или уже сетевой. Ничего не публикуется одним этим нажатием.
4. Если папка локальная, нажмите **«Настроить общую папку»**, подтвердите UAC
   и задайте пароль нового пользователя. Затем снова нажмите кнопку инструкции.
5. На каждом ТВ добавьте показанные параметры в плеер. Для этого не нужно
   нажимать «Установить на все устройства», включать VPN или менять лаунчер.

## Если W: — локальный/внешний диск компьютера

Менеджер создаёт общий ресурс с уникальным именем `TVMovies_<id>` и пользователя
`TVMRead_<id>`. Имя ресурса отличается от имени папки — это нормально. Ресурс
указывает прямо на `W:\.intake`.

Например, если программа показала:

- сервер `192.168.31.10`;
- ресурс `TVMovies_1234abcd`;
- пользователь `МОЙ-ПК\TVMRead_1234abcd`;

то адрес папки будет `smb://192.168.31.10/TVMovies_1234abcd`.
**Не добавляйте /.intake повторно.** Это пример: используйте свои значения,
которые покажет менеджер. Пароль — тот, который вы задали в окне Windows.
PIN-код входа Windows не является этим SMB-паролем.

Компьютер и диск W: должны быть включены и доступны. Домашняя сеть Windows
должна иметь профиль «Частная». Менеджер не меняет профиль сам. Правило TCP 445
создаётся только для указанных IP ТВ и Private-профиля. Ранее существующие
правила не изменяются. Переадресацию TCP 445 на роутере не включайте.

Если W: создан через SUBST, виртуальное подключение или доступен только другому
пользователю, повышенный процесс Windows может его не видеть. Тогда укажите
фактическую локальную папку с фильмами. Ничего не переносите и не удаляйте ради
устранения этой ошибки.

## Если W: — уже сетевой диск/NAS

Повторная публикация через компьютер не нужна и менеджер её не делает.
Он покажет исходный UNC-путь. Например:

`W:` соответствует `\\192.168.31.5\Movies`, поэтому `W:\.intake` — это
`\\192.168.31.5\Movies\.intake`.

В плеере укажите:

- сервер: `192.168.31.5`;
- ресурс: `Movies`;
- подпапка: `.intake`;
- адрес: `smb://192.168.31.5/Movies/.intake`;
- пользователь и пароль NAS/исходного сервера с доступом только на чтение.

Пользователь Windows, созданный менеджером на вашем ПК, не заменяет учётную
запись NAS. Права чтения на исходном сервере задаются там. Сам исходный сервер
должен быть доступен проектору и приставкам напрямую.

## VLC

«Локальная сеть» → «Добавить сервер» / «Новый сервер» → SMB.
Укажите сервер, ресурс и подпапку из менеджера. Затем введите пользователя и
пароль непосредственно в VLC. Названия меню зависят от версии; если ручного
добавления нет на текущем экране, найдите сервер через «Локальная сеть».

Откройте короткий обычный видеофайл для первой проверки. Подключение к папке
не доказывает, что устройство поддерживает конкретный видеокодек.

## Vimu

«Источники» / «Добавить источник» → SMB / Windows share. Используйте те же
сервер, ресурс и подпапку. Учётные данные вводятся в Vimu.

Если установлен только Vimu Installer, сначала завершите установку самого
плеера. Состояние Installer не равно установленному плееру.

## MX Player

Если ваша версия поддерживает SMB2/3, добавьте те же параметры в сетевые
источники. Если не поддерживает: установите X-plore из официального магазина,
откройте LAN → добавить сервер → SMB → нужную папку → «Открыть с помощью» →
MX Player. Сам MX при этом воспроизводит файл, а доступом к SMB занимается
файловый менеджер. Старый SMB1 не включайте.

## Если папка не открывается

- Вводится IP компьютера/NAS, не IP телевизора и не localhost.
- На проекторе адрес 192.168.28.60, у приставок ранее были 192.168.31.232 и
  192.168.31.20. Между подсетями должна существовать локальная маршрутизация.
  Менеджер не создаёт маршруты и не перенастраивает ваш роутер. Если одна сеть
  гостевая или изолированная, разрешите доступ в настройках своей домашней сети.
- Если Windows имеет несколько IP, менеджер предпочитает адрес по маршруту к
  первому указанному ТВ и показывает другие варианты. Проверьте, что выбранный
  адрес достижим также с приставок.
- Проверьте пароль и формат `ИМЯ-ПК\пользователь` для Windows. Для NAS используйте
  его собственную учётную запись.
- Для проверки локальной сети временно остановите VPN в клиенте на ТВ.
  После настройки белого списка INCY/ByeByeDPI медиаплееры должны работать вне VPN.
- Не отключайте брандмауэр и не включайте гостя ради диагностики.

Чтобы убрать доступ, нажмите «Восстановить настройки SMB». Удаляются только
созданные менеджером ресурс, правило, пользователь и его разрешение. Фильмы
и исходные общие папки не удаляются. Пароли не попадают в URL, JSON и журналы.
